WatchWhatMovie

Description
- WatchWhatMovie is a small, browser-based tool to help you decide what to watch, manage a personal watchlist, and track titles you've watched.
- It was created in 2019.

Built with
- HTML
- CSS
- JavaScript

Persistence
- Uses localStorage for persistence (no server required).

Notes
- Lightweight front-end demo; adapt it to your stack as needed.
